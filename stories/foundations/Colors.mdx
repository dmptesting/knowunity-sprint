# Colors

The semantic color tokens from `tokens/tokens.json`, grouped the way design-system.md groups them — not the raw
numbered color ramp underneath, which has no descriptions and isn't meant to be reached for directly. Each swatch
shows the token's dotted path, its resolved CSS value, and the token's own `$description` field.
