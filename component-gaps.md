# Component gaps

Things a screen needed that Storybook didn't have. Written by the `build-screen` skill.

**How this works:** first sighting gets built inline inside the screen and logged here.
Second sighting of the same thing gets built properly — its own directory under
`app/_components/`, a `.module.css`, a `.stories.tsx` and a written description — the
inline copy in the earlier screen is replaced, and the line is struck through here.
